# Home Assistant Add-on: KNX Monitor

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

KNX group monitor and bus diagnostics as a panel in the Home Assistant sidebar.

- Live group monitor with overview cards and history charts
- ETS project import (`.knxproj`, also password-protected, or CSV)
- Health check, commissioning checklist, topology and communication map
- Recordings with real-time replay and PDF export
- Alarm notifications via Home Assistant

Connects directly to your KNX IP gateway via KNXnet/IP tunneling.
See [DOCS.md](DOCS.md) for details.
